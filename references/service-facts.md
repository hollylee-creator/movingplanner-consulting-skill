# 서비스 팩트 시트 (메시지 작성 전 대조용)

> 파일럿 1R 기준. 숫자·링크·조건이 바뀌면 이 파일만 갱신하면 스킬 전체가 최신화된다.
> 변하는 값(마감일·적립률·한정 대상)과 안 변하는 로직(원칙·톤)을 분리해 관리할 것.

## 가치 정의 — 과약속 금지

- 플래너가 주는 것: 일정 정리 + 궁금증 응답 + 신청 대행 + 의사결정 코칭(고르는 기준·순서).
- **신청 대행 대상(2R부터): 이사 · 입주청소 · 부분시공 · 종합시공.** 상담사가 대신 접수한다.
- **자가 신청으로 남은 것: 인터넷 · 렌탈 · 멤버십.** 고객이 딥링크에서 직접 신청. 여기엔 "신청해드릴게요" 금지.
- 플래너가 여전히 안 하는 것: 업체 선택 대행 ❌(매칭된 업체 중 선택은 고객), 견적 비교 대행 ❌.
- 30가지 체크리스트 = 신청자 전원 무료. 개인화 일정표·상담 = 선정(매칭) 고객 한정.
- 선정 안내: 신청해도 전원 상담 아님. 이사 임박 고객 우선 순차.

## 멤버십 (1R 핵심 무기)

- **가입비 100% 환급 = 90일형(3개월).** 가입비(9,900원)를 내면 바로 전액 돌려줘서 "지금 가입은 무료인 셈". 11/30(월)까지 한시 무료.
  - 주의: 사용/혜택 기간은 90일이다. 통화에서 "6개월"로 잘못 안내된 적 있음 → "6개월" 절대 금지, 90일로 통일.
- **적립: 누적 구매액 기준 구간제. 각 구간 요율은 그 구간에 해당하는 금액에만 붙는다(초과분 방식).**

  | 누적 구매 구간 | 요율 |
  |---|---|
  | 100만원 미만 | 적립 없음 |
  | 100~200만 | 1% |
  | 200~300만 | 10% |
  | 300만 초과 | 5% |

  적립은 100만원부터 시작한다. **최대 적립 46만원**(누적 1,000만원 지출 시 = 1만 + 10만 + 700만×5% 35만). 공식 계산기 슬라이더 상한도 1,000만원.
  (이전 팩트 시트의 "최대 45만원"은 1% 구간을 빼고 계산한 오류였음. 46만원으로 정정.)

  **계산 예시(공식 페이지 기준, 이 숫자를 그대로 쓸 것):** 누적 330만원 → (100만×1%) + (100만×10%) + (30만×5%) = 1만 + 10만 + 1.5만 = **12만 5천원**

  참고용 환산표(내부 판단용, 고객에게 표로 주지 말 것):

  | 누적 구매 | 적립 | 실질 요율 |
  |---|---|---|
  | 200만원 | 1만원 | 0.5% | ← 공식 계산기로 확인됨(10% 구간 0원)
  | 300만원 | 11만원 | 3.7% |
  | 330만원 | 12.5만원 | 3.8% |
  | 500만원 | 21만원 | 4.2% |

  ⚠️ **"200만 원어치면 20만 원 적립"은 완전히 틀린 문구다(실제 1만원, 20배 과장). 절대 쓰지 말 것.** 과거 스크립트에 있던 표현이며 전량 교체됨.
  ⚠️ "적립률이 10%예요" 식 단정도 금지. 10%는 200~300만 구간에만 붙는다.
  - 포인트는 무빙패스 이용 기간(90일) 내 **구매확정된** 금액 기준으로 적립되며, 구매확정 후 24시간 이내 지급.
  - 코칭 포인트: 200~300만 구간이 10%로 가장 효율이 좋다. 예산이 200만 근처인 고객은 300만까지 채우면 적립이 1만원 → 11만원으로 뛴다. 판단 재료로만 쓰고(영업 아님), 억지로 더 사게 만들지 않는다.
  - **200~300만 구간 고객에게 적립은 주 혜택이 아니다.** 200만원 지출 시 적립 1만원, 배송비 쿠폰 5만원. 이 구간에선 배송비 쿠폰을 앞세우는 게 정직하고 체감도 크다.

### 총 혜택 구성 (공식 계산기 기준)

무빙패스 혜택 = 가입비 페이백 9,900원 + 배송비 쿠폰 50,000원 + 구매 적립(구간제).

| 누적 지출 | 적립 | 총 혜택 |
|---|---|---|
| 200만원 | 10,000원 | 69,900원 |
| 300만원 | 110,000원 | 169,900원 |
| 500만원 | 210,000원 | 269,900원 |
| 1,000만원 | 460,000원 | 519,900원 |

- **숫자를 직접 말하기보다 공식 '혜택 계산기'로 넘기는 게 가장 안전하다.** 대표 페이지(https://link.ohou.se/ztai61)의 '혜택 계산기' 탭에서 고객이 예상 지출을 넣으면 구간별 적립까지 자동 계산된다. 상담사가 암산해서 틀릴 위험이 사라지고, 고객이 직접 본 숫자라 신뢰도도 높다.
- 공식 명칭은 **무빙패스**다. 페이지·계산기 모두 이 이름을 쓰므로 고객 안내 시 "무빙패스"로 통일하면 페이지와 어긋나지 않는다.
- **배송비 5만원 쿠폰 / 무료배송 쿠폰 여러 장.** (정확한 장수 확정되면 "쿠폰 ○장"으로 교체.)
- **혜택 적용 방식: 가입자는 오늘의집에서 구매하면 적립·배송쿠폰이 자동 적용된다.** "멤버십으로 결제" 같은 별도 행동 불필요. 가입 완료 고객껜 "이제 사시면 자동으로 붙어요"로 안내(재권유 아니라 활용 안심).
- 이사 예정자에게만 비공개 안내. 약 1만 명 사용 중(사회적 증거로 사용 가능, 확인됨).
- **늦으면 소급 안 됨** = 사기 전에 가입해야 적립·쿠폰이 붙는다. 이게 "지금 해두기"의 진짜 이유(단, 밀지 말고 안심 톤으로).
- 대표 페이지: https://link.ohou.se/ztai61 / 일정표 내 '이사준비자료 > 멤버십혜택' 버튼.

- 시기: 이사 후 14일 이내 통지 원칙(일정표 D+1 '한전ON 명의변경' 항목).
- 아파트는 관리사무소가 관리비로 전기요금 일괄 처리하는 경우도 있어 직접 처리 불필요할 수 있음 → "관리사무소에 먼저 확인" hedge로 안내. 빌라·단독은 한전 직접.

### 매칭 상태 조회 (상담사 권한 — 2R)

대행 접수 이후 상담사가 조회할 수 있는 필드:

| 필드 | 값 | 평시 고객 안내 |
|---|---|---|
| 매칭 상태 | 매칭 대기 / 매칭중 / 매칭완료 / 매칭실패 | ⭕ 이것만 알려준다 |
| 매칭된 업체 수 | 숫자 | 요청 시에만 |
| 매칭된 업체 이름 | 업체명 | 요청 시에만 |
| 업체 매칭 승인상태 | 수락대기 / 상담거절 / 상담진행 | 요청 시에만 |

**평시 원칙: 매칭 상태만 전달한다.** 업체 수·이름·승인상태는 고객이 직접 확인을 요청한 예외 케이스에만 꺼낸다. 먼저 흘리지 않는다.

이유:
- 업체 이름을 먼저 말하면 추천처럼 읽힌다. 업체 선택은 고객 몫이라는 경계가 무너진다.
- 업체 수를 먼저 말하면 적을 때 불안만 준다(지역·일정에 따라 원래 차이가 난다).
- '상담거절'을 그대로 전달하면 고객이 자기 건이 문제라고 느낀다. 업체 일정 사정이 대부분이다.

요청받아 승인상태를 전할 때는 **진행 중인 곳 위주로** 말한다. "한 곳은 거절, 두 곳은 대기"보다 "지금 두 곳이 진행 중이고 한 곳은 일정이 안 맞았어요"가 같은 사실의 정확한 전달이다.

### 이사업체 매칭 개수·재매칭 정책 (팀 확인, 정책서엔 없던 내용)
- 최대 4개(무조건 아님), 평균 3개 정도. 지역·일정에 따라 차이. 일정이 멀면(업체가 임박 건 우선) 적게 매칭될 수 있음.
- 매칭은 신청 후 24시간 내까지. 그 뒤로는 더 이상 추가 매칭 안 됨(기다려도 안 늘어남).
- 부족하면 재신청 추천 = 이사 45일 이내에 신청(이사일 45일 전쯤부터)하면 매칭 잘 됨.

## 과장·확약 금지 항목 (재확인)

- 적립: 구간제이며 초과분 방식. "무조건 10%" 금지, "200만이면 20만" 금지. 예시는 공식 숫자(330만 → 12.5만)만 사용.
- 인터넷 사은품 금액 확약 금지(변동).
- 시공 VIP 3%는 계약 조건부.
- 키친 싱크볼 = B2B(업체용), 고객 안내 금지.
- 업체 선택·견적 비교를 우리가 해준다는 뉘앙스 금지(신청 접수 대행은 OK).
- 인터넷·렌탈·멤버십에 "신청해드릴게요" 금지(대행 대상 아님).
